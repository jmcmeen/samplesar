# Papers

Manuscripts built on samplesar, one folder per paper. Each holds its outline,
its Methods material (which doubles as the reference the code is checked
against), and later its draft, figures and the scripts that make them.

Data never goes in here: scripts read it from wherever it lives and write
figures and tables only.
